# Chapter 1: Variables

## 1.1 Learn Go

- A program needs `package main` together with `func main()`. A `main` package without `func main` does not build. Only `main` packages become binaries with `go run` or `go build`, which is why every lesson lives in its own directory.
- `fmt.Println` returns `(n int, err error)`. Ignoring the error is normal for stdout. The same habit is a bug with files, sockets or a `bufio.Writer`, where a failed write or a missing `Flush` loses data without any error.

## 1.2 Declaring a Variable

- `var x T` gives `x` the zero value of `T`: `0`, `""`, `false`, or `nil` for pointers, slices, maps, channels, funcs and interfaces. Go never has an uninitialized variable.
- Idiom: use `var x T` when the zero value is the starting state you mean, like a counter or a `sync.Mutex`. When a real value is known at declaration, use `x := v`, or `var x = v` at package level. A `var` followed by an assignment on the next line, as in this lesson, is the shape reviewers ask to collapse.
- Useful zero values are a design goal: `bytes.Buffer`, `sync.Mutex` and `strings.Builder` all work without a constructor.
